# F1 Race Simulator

Курсовий проєкт з об'єктно-орієнтованого програмування: симуляція гонки Формули 1 сезону 2026 року мовою C# (.NET 8, Windows Forms).

Програма проводить повний гоночний вікенд на будь-якій із 23 трас календаря 2026 року з усіма 22 пілотами 11 команд:

1. **Кваліфікація** у форматі F1: Q1 (18 хв) → Q2 (15 хв) → Q3 (12 хв), після Q1 і Q2 вибувають по 6 пілотів. Кожен виїзд — коло виїзду, швидке коло і коло повернення; бувають помилки й скасовані через межі траси кола, а траса з часом «гумується».
2. **Гонка** зі старту з місця за результатами кваліфікації: шини зношуються, пілоти заїжджають на піт-стопи за своєю стратегією, обганяють, атакують і захищаються.
3. **Фініш як у реальності**: після клетчастого прапора боліди не зупиняються на лінії, а проїжджають коло охолодження і заїжджають у парк-ферме (трійка призерів — окремо, решта — у свої бокси).
4. **Очки чемпіонату** (25-18-15-12-10-8-6-4-2-1) нараховуються після кожного Гран-прі. Вікно підсумків показує протокол і таблицю чемпіонату зі зміною місць, а кнопка «Наступний етап» відкриває наступну трасу календаря. Чемпіонат автоматично зберігається між запусками.

Схеми трас — в **офіційній орієнтації F1** з номерами поворотів і трьома кольоровими секторами. Швидкість болідів уздовж кола йде за справжнім профілем швидкості з офіційної телеметрії, тому на прямих вони швидші, а в поворотах повільніші.

**Телеметрія**: для обраного пілота — швидкість, передача, оберти, газ/гальмо, знос і температура шин, температура і знос двигуна, паливо, заряд ERS, режим їзди, часи кіл і секторів. Вкладка «Телеметрія всіх пілотів» показує те саме одразу для всіх 22 болідів.

## Що потрібно

- Windows 10 або 11.
- Visual Studio 2022 (версія 17.8 або новіша) з робочим навантаженням **«.NET desktop development»** («Розробка класичних застосунків .NET»).
- .NET 8 SDK (встановлюється разом із Visual Studio).

## Як запустити

1. Склонуйте репозиторій або завантажте ZIP (кнопка **Code → Download ZIP**).
2. Відкрийте файл `F1RaceSimulator.sln` у Visual Studio.
3. Переконайтеся, що стартовий проєкт — **F1RaceSimulator.WinForms** (правою кнопкою по проєкту → *Set as Startup Project*).
4. Натисніть **F5**.

Під час першої збірки Visual Studio сама завантажить пакети NuGet для тестів (потрібен інтернет).

## Як запустити тести

**Test → Run All Tests** (або `Ctrl+R, A`). Вікно результатів — **Test → Test Explorer**.
З командного рядка: `dotnet test`.

│       ├── TrackRenderer            малювання траси, секторів, номерів поворотів і болідів (GDI+)

## Принципи ООП і патерни в коді

| Що | Де |
| --- | --- |
| Інкапсуляція | `Car`: стан змінюється лише методами `Advance`, `EnterPitLane`, `ChangeTyres`; температура і паливо — лише через `Update` компонента |
| Абстракція | абстрактні класи `CarComponent`, `Tyre`; інтерфейси `ITrackSession`, `IPitStrategy`, `IRaceObserver`, `IQualifyingObserver`, `IRandomSource` |
| Наслідування | `Tyre`, `PowerUnit`, `FuelTank`, `ErsBattery` ← `CarComponent`; `SoftTyre`, `MediumTyre`, `HardTyre` ← `Tyre`; `AggressivePitStrategy` ← `ThresholdPitStrategy` |
| Поліморфізм | `CarComponent.Update` (кожен компонент оновлюється по-своєму), `Tyre.PaceMultiplier` (перевизначено в `SoftTyre`), `IPitStrategy.ShouldPit`, `ITrackSession` (`TrackRenderer` однаково малює і кваліфікацію, і гонку) |
| Strategy | `IPitStrategy` і дві стратегії піт-стопів |
| Observer | `Race` → `IRaceObserver`, `QualifyingSession` → `IQualifyingObserver` (`EventLogObserver`, `MainForm`) |
| Factory | `TyreFactory`, `PitStrategyFactory`, `CarFactory` |
| Singleton | `Championship.Instance` |

## Дані

Усі дані сезону лежать у папці `data/` у форматі JSON і копіюються поруч із програмою під час збірки. Їх можна змінювати без перекомпіляції коду.

- `teams.json` — 11 команд: назва, колір, умовний рейтинг боліда.
- `drivers.json` — 22 пілоти: команда, умовні рейтинги швидкості, стабільності й дбайливості до шин, стратегія піт-стопів.
- `tracks.json` — 23 етапи календаря 2026: довжина кола, кількість кіл, типовий час кола, абразивність, погода, температура повітря, схема траси (контур, піт-лейн, номери поворотів, межі секторів) і профіль кола (швидкість, передача, оберти, газ, гальмо — 240 точок).

Склади команд — за даними [Formula1.com](https://www.formula1.com/en/latest/article/2026-line-ups-confirmed-in-full-who-is-on-the-grid-for-next-season.3TyLfOUjOwpBKOp3KX1PiS). Рейтинги пілотів і болідів, а також числа моделі температур, палива та ERS умовні — це навчальна модель, а не точна фізика. Схеми трас, номери поворотів, сектори і профілі швидкості побудовані з офіційних даних хронометражу F1, опублікованих [TracingInsights](https://github.com/TracingInsights) (зібрані бібліотекою [FastF1](https://github.com/theOehrly/Fast-F1), Apache-2.0) — див. `tools/trackdata/`. Для Мадрида і Сепанга офіційних даних про повороти немає: номери знайдено за кривиною траси (у Мадриді 22 повороти, як в описі траси від [Pirelli](https://press.pirelli.com/2026-spanish-grand-prix---preview/)). Піт-лейни намальовані схематично.

## Примітка про версію .NET

Проєкт націлений на .NET 8 (LTS), який працює у Visual Studio 2022. Підтримка .NET 8 від Microsoft триває до 10 листопада 2026 року. Щоб перейти на .NET 10, змініть `net8.0` на `net10.0` (і `net8.0-windows` на `net10.0-windows`) у трьох файлах `.csproj` і відкрийте рішення у Visual Studio 2026.
